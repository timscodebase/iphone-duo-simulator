WebMCP & AI Agent Readiness

Exposes posture control as an MCP tool so autonomous agents can test your website in different hardware states.

navigator.modelContext Tool Registration 
// The extension registers the posture control tool with the page's model context
navigator.modelContext.registerTool({
  name: 'iphone_duo_set_posture',
  description: 'Controls simulated physical posture of the iPhone Duo (folded, unfolded, partially_folded, split_view).',
  inputSchema: {
    type: 'object',
    properties: {
      posture: {
        type: 'string',
        enum: ['folded', 'unfolded', 'partially_folded', 'split_view'],
        description: 'Physical hardware posture of the device'
      },
      angle: {
        type: 'number',
        description: 'Fold angle in degrees (60° to 160°) for partially_folded pose'
      }
    },
    required: ['posture']
  }
}, async ({ posture, angle }) => {
  // Emulates folding transition on inspected page
  return { status: 'success', posture, angle: angle || 110 };
});
